Este repositório reúne os projetos desenvolvidos no contexto do **DCTA (Centro de Difusão de Tecnologia e Conhecimento)**, abrangendo três principais áreas de atuação:

| Área | Descrição |
|------|-----------|

| 🎨 **Design** | Layouts, identidade visual e materiais gráficos institucionais |
| 📸 **Fotografia** | Registros e tratamento de imagens para acervo institucional |

## 🚀 Como Usar

### Pré-requisitos

- Git instalado
- Python 3.8+ (para scripts Python)
- Editor de código (VSCode, Sublime, etc.)

### Instalação

```bash
# Clone o repositório
git clone https://github.com/heglas/DCTA.git

# Acesse o diretório
cd DCTA

# Explore os projetos
ls -la
```

### Estrutura de Branches

```
main (produção)
 ├── develop (desenvolvimento)
 └── feature/* (novas funcionalidades)
```

## 🤝 Contribuições

Contribuições são bem-vindas! Para contribuir:

1. **Fork** o projeto
2. Crie uma **branch** para sua feature (`git checkout -b feature/MinhaFeature`)
3. **Commit** suas mudanças (`git commit -m 'Add: MinhaFeature'`)
4. **Push** para a branch (`git push origin feature/MinhaFeature`)
5. Abra um **Pull Request**

### Diretrizes

- Siga o [Conventional Commits](https://www.conventionalcommits.org/)
- Mantenha a consistência de código
- Adicione documentação para novas funcionalidades
- Respeite a estrutura de pastas existente
